# Assets-Threats-and-Vulnerabilities_Activities_GCS
This repository contains some activities of the series Assets, Threats, Vulnerabilities Course under Googel Cybersecurity Specialization.

# Access-control
This folder contains a Information about an Incident in a worksheet.

# Data-Leak
A worksheet examining security of an incident in an organization

# Home-Assets-Inventory
An analysis of assets in your home in an inventory explaining access and security information about those assets present.

# Parking-Lot-USB
Activity to enhance security measures when handling USB devices.

# Risk Register
Creating a registry of risk in an organization's environment
